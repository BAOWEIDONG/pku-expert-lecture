# 北大医疗国际医院 · 专家讲座预约平台

面向保险公司与企业客户的入企专家讲座、健康活动预约 H5。客户端与院方工作台合并在同一站点内，可直接在手机浏览器或微信中打开。

## 访问

- 线上：https://baoweidong.github.io/pku-expert-lecture/
- 院方入口：首页右上角「院方入口」或「我的 → 院方工作台」
- 体验账号：`PKU-HMC-001` / `123456`

## 功能

**客户端**
- 三级专家资源（院士·大咖 / 专家咨询·主任 / 专业医生），展示合作方式与提前申请周期，不在页面展示具体价格数字
- 院士专家顾问团（12 位院士）与 43 位院方专家，卡片含照片/院士标识 + 职称 + 科室 + 擅长简介 + 查看详情，支持科室筛选、模糊搜索
- 专家详情、可预约日期与上午/下午/晚间时段
- 三步活动预约：活动信息、联系人、确认提交
- 预约成功页、短信提醒说明、我的预约、方案查看与确认、取消预约
- 消息中心、活动须知、联系院方

**院方端**
- 工作台：待回复/已回复/已确认统计、待办、最新预约
- 预约管理：状态筛选、搜索、客户与活动需求
- 回复方案：课题、会议内容、活动流程、时间安排、院方对接人、备注
- 短信提醒：总开关、事件开关、提前天数、院方接收人、模板、模拟发送记录
- 专家排期：按专家开关未来可约时段

## 数据说明

- 医生资料与头像来自北京大学国际医院官网公开医师库（pkuih.edu.cn），仅用于本项目展示。
- 院士名单来自北大医疗集团院士专家顾问团首批公开成员。
- 费用以院方正式方案为准；排期、预约与短信记录均为本机 localStorage 演示数据，不接入真实短信网关。

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080/
```

## 技术

零依赖、零构建：`index.html` + `app.js` + `data.js` + `assets/`，直接部署 GitHub Pages。数据保存在 `localStorage`（键 `pku_lecture_v1`）。
